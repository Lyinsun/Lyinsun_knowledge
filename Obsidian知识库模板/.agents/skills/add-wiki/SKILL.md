# Add Wiki

Search for a duplicate first. Route uncertain material to `00-Inbox/`; put reusable methods, concepts, decisions, and insights under the matching `05-Knowledge/` subdirectory. Use a `99-Templates/` file, complete frontmatter, add precise `[[wikilink]]` references, and preserve sources plus verification limits.

Before writing, describe the file and purpose. After a multi-note or structural change, run the template lint Skill.

> - **实线与实线框（已完成/现有基线）**：表示现有线上稳定系统，或本次方案中已交付通过的链路（绿色高亮边框）。
> - **虚线与虚线框（设计中/进行中）**：表示本次专项的核心改造点、新增设计或正在实施的链路（黄色/橙色虚线边框 `stroke-dasharray: 5 5`）。
> - **灰色与中划线（废弃/不在范围内）**：表示明确不在本次专项范围（Out-of-scope）或计划下线替换的模块。

# 示例变更流程

## 目标

演示一个依赖接口契约的最小变更流程，所有步骤均为模板示例。

## 步骤

1. 更新接口笔记中的合成字段或状态说明。
2. 同步更新服务笔记与架构笔记的关联说明。
3. 运行知识库检查，确认双向链接未断开。
4. 审阅差异后提交变更。

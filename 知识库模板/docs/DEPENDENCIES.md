# 依赖与兼容性

## 必需

| 依赖 | 用途 | 版本要求 |
| --- | --- | --- |
| Git | 版本控制、审阅和同步 | 任意当前稳定版 |
| Markdown | 阅读与编辑知识内容 | CommonMark/GFM 兼容 |
| Python | 运行本地只读检查 | 3.10 或更高，标准库即可 |

## 推荐但可选

| 工具 | 用途 | 没有它时 |
| --- | --- | --- |
| `rg`（ripgrep） | 快速全文检索 | 使用编辑器搜索或 `grep` |
| YAML 语法高亮 | 编辑 frontmatter | 可直接编辑纯文本 |
| 支持仓库级 Skills 的 Agent | 自动执行知识库流程 | 按 `AGENTS.md` 手工执行 |
| Obsidian 或其他 Markdown 编辑器 | 浏览和编辑体验 | 不影响仓库结构或检查 |

## 明确不依赖

本模板不要求云数据库、向量数据库、浏览器扩展、特定在线文档平台、内部命令行工具或网络访问。若未来引入新工具，先在此文件记录版本、用途、替代方案和数据边界。

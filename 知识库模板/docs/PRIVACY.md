# 隐私、脱敏与共享规则

## 禁止提交

- 凭据、令牌、私钥、会话信息、连接串、Cookie 和环境变量值。
- 个人姓名、账号、邮箱、电话、地址、头像或可识别个人的聊天记录。
- 真实组织、客户、项目代号、内部域名、主机名、仓库地址、工单地址和生产标识。
- 未脱敏日志、数据库导出、屏幕截图、音视频转录和受限原始文档。

## 可提交的替代形式

| 不应保留 | 使用的替代 |
| --- | --- |
| 真实系统名 | `Example System` |
| 内部 URL | `https://example.invalid/path` |
| 人员信息 | `ROLE-A` 或 `TEAM-A` |
| 真实标识符 | `resource-123`、`request-456` |
| 原始日志 | 最小化的虚构示例，并标注为示例 |

## 处理流程

1. 判断材料是否包含受限信息；不确定时按受限处理。
2. 在受控系统保存原文，不提交到本仓库；来源记录只写必要的非敏感元数据和摘要。
3. 用替代符重写示例、日志和架构图，确保无法反推出真实主体。
4. 在提交和对外分享前运行 `knowledge-lint`，再由内容所有者人工复核。

自动检查只能发现常见模式，不能替代人工判断。发现疑似泄漏时，停止复制、限制传播，并按所在组织的安全流程处理。

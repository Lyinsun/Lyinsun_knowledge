# 从零初始化

## 1. 复制并命名

将此目录复制到新的 Git 仓库，编辑 `kb.config.yaml` 中的仓库名称、默认分支、语言和内容目录。不要把来源仓库的用户配置、`.git`、编辑器状态或私密资料一同复制。

## 2. 建立最小导航

在 `index/topic-map.md` 填写当前系统、领域和关键流程的主题入口。每个入口先链接到一篇范围清晰的权威笔记，而不是罗列所有文件。

## 3. 导入第一份材料

1. 先确认材料可被此仓库保存和共享。
2. 在 `sources/` 建立来源记录，写明出处类型、获取日期、可见性和摘要。
3. 从 `_templates/knowledge-note.md` 创建一篇笔记，关联来源 ID。
4. 更新主题地图，运行检查。

## 4. 配置 Agent（可选）

若使用支持仓库级 Skills 的 Agent，保留 `.agents/skills/` 和 `AGENTS.md`。Agent 应在执行任务时读取对应 `SKILL.md`；没有 Agent 时，这些文件仍是人类可执行的流程说明。

## 5. 选择编辑器（可选）

本模板可在任意 Markdown 编辑器中使用。若选择 Obsidian、VS Code 或网页 Git 平台，仅将其视为界面；不要将编辑器私有配置、链接格式或插件当作知识库依赖。
